# Test Files for Ephemeral Theme

Эта папка содержит тестовые файлы для проверки подсветки синтаксиса темы Ephemeral в различных языках программирования.

## Файлы

- **javascript-example.js** - JavaScript/ES6+ примеры (классы, функции, async/await, template literals)
- **typescript-example.ts** - TypeScript примеры (интерфейсы, типы, generics, enums)
- **python-example.py** - Python примеры (классы, функции, type hints, декораторы)
- **html-example.html** - HTML с встроенным CSS и JavaScript
- **css-example.css** - CSS примеры (переменные, селекторы, медиа-запросы, анимации)
- **markdown-example.md** - Markdown примеры (заголовки, списки, таблицы, код)
- **json-example.json** - JSON структура данных
- **rust-example.rs** - Rust примеры (структуры, traits, pattern matching, async)

## Как использовать

1. Откройте любой из файлов в редакторе с применённой темой Ephemeral
2. Проверьте, как выглядят различные элементы синтаксиса:
   - Ключевые слова
   - Функции и методы
   - Классы и типы
   - Строки и комментарии
   - Числа и константы
   - Операторы и скобки

## Что проверять

- ✅ Цвета соответствуют киберпанк-палитре
- ✅ Контраст достаточен для чтения
- ✅ Различные языки подсвечиваются корректно
- ✅ Комментарии легко отличить от кода
- ✅ Строки, числа и ключевые слова различимы
- ✅ Функции и классы выделяются акцентным цветом
